# Root-cause fixes (Nov 25 2026)

Rule: free and open source only, no card, no new accounts, no token. "Root" means the cause is removed. Where that is impossible under those rules, this file says so and names what is reduced instead.

| Risk | Root cause | Root fix | Status | Needs from the user |
|---|---|---|---|---|
| Refresh triggers (P1, G4) | Only external clocks trigger refreshes, and the free GitHub scheduler is best-effort | Several independent triggers: the live prices and order book no longer depend on refreshes (done); GitHub cron now has two schedules (05:17 UTC daily and 03/09/15/21 UTC at minute 47, added Nov 25); Instinct session wakes; keeper wakes; footer button | Done as far as free tools allow. No free always-on scheduler exists without credentials. Unproven until the first scheduled run appears in Actions | Nothing |
| Push depends on my saved GitHub login (P4) | Without a token, the browser session is the only way in | Cannot be removed under the no-token rule. Reduced: the site and refreshes run without me; a push is only needed for code changes | Reduced, not removed | If he ever accepts a token it removes this; he said no, so nothing |
| aggTrades has no fallback (P7) | Only Binance publishes trade-level data free and current. Checked: api.binance.com and siblings return 451 from here; OKX and Gate.io history is too slow to page for 6 hours of trades | Graceful degrade: on failure the module fails, last good data stays and is flagged stale, the card shows its age. Binance daily archive files can fill completed days later | Reduced, not removed | Nothing |
| Phone/Safari background (P15) | The browser pauses hidden tabs | Page restarts polling when it becomes visible and shows age and a stale badge while paused (done); a real-phone check is the only proof left | Mitigated | One 2-step phone test (G9) |
| Push vs refresh race (P3) | Two workflows write to main | Both already run `git pull --rebase` before `git push`; refresh runs are serialized. A shared lock across workflows is the full fix and needs a workflow-file edit; the race window is seconds and has not occurred | Mitigated; will add the shared lock if it is ever seen | Nothing |
| 0.5% flag never fired live (G1, P10) | Real exchanges rarely differ by 0.5% | The flag logic is tested in the module and in the page with simulated mismatches. A live proof is only possible when a real mismatch happens. Proposed next: keep a small history of the largest real difference per refresh, so a quiet check can be told from a dead check | Proposed, not built | Nothing |
| Demo agent traps (P13) | Look-ahead bias, ignored fees and slippage, overfitting, short history | Fixed by design before any agent is built: (1) walk-forward splits, never random; (2) signals use only candles closed before the decision; (3) every result includes fees and a slippage assumption; (4) report sample size and confidence interval, not just hit rate; (5) tune on one period, test untouched on a later one, once; (6) paper-trade before any claim; (7) 98% claim only if the lower confidence bound passes | Written as a rule set; harness not built (B5-B7) | Approval to start B5 |
