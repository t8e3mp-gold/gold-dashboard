# References library

Everything the user sends (links, posts, screenshots, videos) and every source we rely on gets one entry here, so agents look it up instead of recalling it from memory. This repo is public: only public links and our own summaries go here. No private screenshots, no personal data, no keys.

## How to add an item
1. Copy `_TEMPLATE.md` to `R-YYYYMMDD-NN-short-name.md` (date the item arrived, NN = 01, 02 ... that day).
2. Fill every field. Mark each fact **verified** (with the exact URL and date checked) or **reported** (someone else's reading, not checked by us). Never write a fact you did not read.
3. Add one row to the index below.
4. Verdict is one of: `use`, `use-with-limits`, `ideas-only`, `rejected` (say why, for example needs a card, paid, self-hosted, licence).
5. Stage plans and module docs cite entries by id, for example `[R-20261125-03]`.
